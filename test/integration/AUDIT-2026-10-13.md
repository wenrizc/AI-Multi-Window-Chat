# Integration Audit: 2026-10-13

Test target: workspace version 2.0.0 built into `release/`, loaded as a real MV3 extension in isolated Playwright Chromium. Codex's embedded browser does not support installing this extension.

## Results

- Vitest: 312 passed across unit, service integration and browser component suites.
- Playwright: 20 passed, including four added packaged-extension workflow tests.
- TypeScript: passed.
- Real imported DeepSeek configuration: connection probe, streaming first turn, non-streaming follow-up, persisted messages, session restoration and narrow/dark UI passed.

## Workflow Coverage

- Provider save/reload, configured endpoint connection test and malformed JSON import retaining saved data.
- Prompt create/save/reload, JSON export content, cancelled deletion and confirmed deletion.
- Image attachment decoding/preview/removal/send, attachment retention after edit and regeneration.
- Markdown table rendering, regeneration versions, sibling navigation, edit cancellation and saved edited branch.
- HTTP 401 non-retryable error, HTTP 500 retry, no duplicate user messages after retry, delayed request cancellation and missing search-key warning without sending a request.
- Selection toolbar, embedded conversation, fullscreen/minimize/restore/close controls, separate restored history window, history filtering/export/deletion.
- Existing tests cover branches, live settings changes, prompt selection persistence, narrow layouts and localization.

## Fixed Finding

Markdown tables were parsed but displayed without cell spacing or borders. `chat-window.css` now defines table cell spacing, borders, header background and bounded horizontal scrolling. The packaged test verifies cell spacing; screenshots verify the result.

## Evidence

Screenshots in `test-results/workflow-audit/`: attachment preview and answer, regenerated/edited branches, authentication/retry/cancellation/search-key states, settings/import/prompt, selection toolbar, embedded/fullscreen/minimized/restored-history windows and history filtering/deletion.

Real API screenshots are in `test-results/live-import/`. Screenshot files can be replaced or removed by subsequent Playwright runs.

## Limits

This is evidence for the tested workflows, not proof of all possible inputs. Search tool execution is verified by mocked service integration, not a live Tavily request. Image transmission is verified against a local API server, not a remote vision model. Native Chrome toolbar popup behavior, other browser versions, OS-specific shortcuts while focus is inside an iframe, and long-duration MV3 suspension were not fully exercised. Test profiles are isolated and do not replace the user's browser configuration.
